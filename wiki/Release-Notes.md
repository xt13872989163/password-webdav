# Release Notes

## 1.0.1

`1.0.1` 主要修复登录自动化，并补齐发布 zip 流程。

### 做了哪些升级

- 点击账号右上角登录按钮后，插件会打开该账号的网址。
- 如果页面已经是登录后的首页、工作台、控制台，插件会直接标记登录成功。
- 如果页面是标准用户名和密码表单，插件会自动填入账号密码并提交一次。
- 如果页面出现验证码、OTP、账号选择、授权确认等风险步骤，插件不会继续自动操作，会让用户手动处理。
- 同一个账号重复点击登录时，会聚焦已有标签页，避免重复打开。
- 不同账号可以并行登录，登录状态互不影响。
- 保存密码提示等待时间进入系统设置，默认 `5s`，可配置 `1s` 到 `15s`。
- 保存密码提示只会在提交登录并确认进入已登录状态后出现，减少误弹。
- 修复 Chrome content script 构建问题，避免出现 `Cannot use import statement outside a module`。
- 新增 content script 构建校验，构建阶段会检查是否误输出顶层 `import/export`。
- 发布流程升级：推送 `v*` tag 后，GitHub Actions 会自动构建扩展并发布 zip。

### 用户能感知到的变化

- 点“登录”后不应该再长期卡在“登录中”。
- 标准登录页会更稳定地自动填账号密码。
- 如果点开就是首页，会直接显示已进入，不会继续等待登录表单。
- GitHub Release 页面会提供 `password-webdav-extension-v1.0.1.zip`。

## 1.0.0

`1.0.0` 是第一个可用版本，功能目标是把 Password WebDAV 做成一个可直接安装使用的 Chrome 密码管理插件。

### 基础能力

- 只保留 Chrome 插件形态，不再提供 web 版本。
- 后端直接使用 WebDAV，不需要自建 API 服务。
- WebDAV 根目录固定为 `PasswordWebDAV/`。
- 支持配置 WebDAV 地址、用户名、密码或应用密码、vault 子路径。
- 支持解锁已有 vault，也支持首次自动创建加密 vault。
- 保存时会自动创建 `PasswordWebDAV/` 下缺失的父目录。

### 密码管理

- 新增、编辑、搜索、删除密码条目。
- 支持标题、网址、用户名、密码、文件夹、标签、备注。
- 保存密码时可以选择文件夹，也可以编辑标题。
- 主界面尽量保持简洁，详细字段放在设置或详情里。
- 密码默认显示为 `********`，点击眼睛图标才临时显示。
- 可以复制账号、复制密码、手动填充当前登录页。

### 文件夹和分类

- 支持文件夹视图和全部账号视图。
- 支持树形文件夹和子文件夹。
- 支持创建、删除、重命名文件夹。
- 支持拖拽移动文件夹。
- 支持把账号拖拽到文件夹里完成分类。
- 删除文件夹时，里面的账号会移动到未分类，不会被一起删除。

### 自动提示和保存

- 在账号输入框输入内容后，插件会根据当前域名和输入内容提示匹配账号。
- 当前域名匹配的账号优先展示。
- 如果当前域名有匹配结果，不再混入其他网站结果。
- 登录成功后，插件会提示是否保存识别到的新账号密码。
- 插件不会静默保存密码，必须用户点击保存确认。

### 设置和体验

- 支持 `zh/en` 语言切换。
- 支持多种主题。
- 支持系统设置页维护主题、语言、WebDAV、保存提示等待时间等配置。
- 操作尽量提供 loading 或结果提示，避免点击后没有反馈。

### 安全说明

- WebDAV 上只保存加密后的 vault 文件。
- `salt` 和 KDF 参数会跟密文一起保存，它们不是秘密，作用是让同一个主密码在不同 vault 中派生出不同密钥。
- 主密码不会保存到 WebDAV。
- 解锁后的 vault 和当前会话主密码只放在 `chrome.storage.session`，锁定或关闭浏览器后会清掉。
- 插件不能直接读取 Google Password Manager 已保存密码。
