# FAQ

## 忘记主密码怎么办？

无法恢复。主密码没有保存，WebDAV 里只有密文。忘记主密码后，只能从你自己保留的备份或其他仍然解锁的设备中恢复。

## salt 是秘密吗？

不是。salt 会跟密文一起存到 WebDAV。它的作用是让同样的主密码在不同 vault 中派生出不同的密钥。

## 为什么不是直接用主密码加密所有密码？

当前实现会先生成随机 vault key，用 vault key 加密密码库，再用主密码派生出的 wrapping key 加密 vault key。这种结构更灵活，以后支持修改主密码时可以只重新包裹 vault key。

## WebDAV 密码安全吗？

Vault 里的网站密码是加密的，但 WebDAV 账号密码本身会保存在本地浏览器扩展设置里。建议使用 WebDAV 应用密码，并只在可信设备上使用。

## 为什么关闭弹窗后，不用重新输入主密码？

因为当前版本会把主密码和解锁后的 vault 暂存在 `chrome.storage.session`，作用范围只限当前浏览器会话。

这能让你：

- 关闭弹窗再打开时继续管理和保存
- 登录后点“保存到 Password WebDAV？”时不必再次输入主密码

点击“锁定”或者关闭浏览器后，这些临时数据会被清掉。

## 登录 GitHub 后为什么没有提示保存？

旧构建只支持手动新增和手动填充，不会自动抓取登录表单。新版会在提交标准密码表单后临时记录候选账号，并在登录页跳转后提示“保存到 Password WebDAV？”。使用前需要先打开插件并解锁 vault；如果没有解锁，点击保存会要求你先解锁。

少数网站使用非标准登录组件、第三方 iframe 或特殊多步登录流程时，可能仍然识别不到。遇到这种情况可以先手动新增，后续再按站点适配。

## 保存到子目录会 404 吗？

插件保存时会先用 WebDAV `MKCOL` 自动创建父目录。如果仍然 404，通常是 WebDAV 根地址或账号权限不对。

## 标签和备注有什么意义？

- `标签`：给自己做额外检索词，比如 `work`、`finance`、`server`
- `备注`：记录恢复码、账号用途、登录说明、成员归属之类的补充信息

它们都不是必填字段，所以插件里默认收在 popup 的“设置 / 详情”视图里。

## 删除文件夹会把里面的密码一起删掉吗？

不会。删除文件夹时，文件夹本身会删掉，但里面以及子文件夹里的密码条目会统一移到“未分类”。

## 密码为什么默认看不到？

主界面默认把密码显示成掩码，避免在弹窗里直接暴露。需要时可以点“显示”临时展开，再点一次“隐藏”收回。这个状态只存在当前界面，不会写回 WebDAV。

## 扩展填充失败怎么办？

有些网站使用自定义登录组件，可能没有标准的 `input[type="password"]`。当前版本只做基础字段识别，后续可以按网站增加适配。

## 如何备份？

备份 WebDAV 上的 `password-vault.json`。它是密文文件，仍然建议放在私有位置并定期备份。
