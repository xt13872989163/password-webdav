# Password WebDAV

`Password WebDAV` 是一个只保留 Chrome 插件形态的密码管理工具。它直接把加密后的 vault 文件存到 WebDAV，不需要单独后端，也不再提供 web 版页面。

## 功能

- 在 Chrome 插件弹窗里创建或解锁加密密码库
- 新增、编辑、搜索、删除密码条目
- 支持文件夹和子文件夹分类
- 主界面支持“文件夹视图 / 全部账号视图”切换
- 主界面支持密码默认隐藏、按需显示
- 支持拖拽移动账号到文件夹，也支持拖拽移动文件夹
- 支持在列表里直接删除条目
- 支持删除文件夹；删除后其中条目会自动移到“未分类”
- 复制账号、复制密码、一键填充当前登录页
- 登录成功后提示是否把识别到的账号密码保存到 WebDAV
- 保存时自动创建 `PasswordWebDAV/` 下缺失的父目录

## 快速开始

安装依赖：

```bash
npm install
```

构建插件：

```bash
npm --workspace @password-webdav/extension run build
```

构建产物目录：

```text
apps/extension/dist
```

## 安装到 Chrome

1. 打开 `chrome://extensions`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择 `apps/extension/dist`

## 如何使用

1. 点击 Chrome 工具栏里的 `Password WebDAV` 图标
2. 填写 WebDAV 根地址、用户名、密码或应用密码
3. 填写 vault 子路径，例如 `password-vault.json` 或 `work/password-vault.json`
4. 输入主密码
5. 点击“解锁或创建”

注意：

- 根目录固定是 `PasswordWebDAV/`
- 设置里只能填写它后面的子路径
- 最终文件会保存到类似 `PasswordWebDAV/work/password-vault.json`

如果 WebDAV 上还没有这个 vault 文件，插件会自动创建；以后保存时也会自动创建缺失的父目录。

## 解锁后怎么管理

解锁后可以：

- 通过头部切换 `文件夹` 和 `全部` 两种视图
- 点击加号新增条目
- 在左侧创建文件夹，例如 `工作/GitHub`
- 在列表里直接复制、填充、显示 / 隐藏密码、删除
- 把账号拖到目标文件夹上，直接完成归类
- 把文件夹拖到另一个文件夹上，移动整个文件夹树
- 点击头部 `设置` 进入详细维护界面，编辑标题、网址、用户名、密码、文件夹、标签和备注

补充说明：

- `标签` 适合做额外检索词，比如 `work`、`finance`
- `备注` 适合保存恢复码、登录说明、二次验证提示等
- 它们不是必填，默认放在 `设置 / 详情` 视图里

## 删除规则

- 删除条目：可以直接在列表里删，也可以在 `设置 / 详情` 里删
- 删除文件夹：文件夹本身会被删除，原来在这个文件夹及其子文件夹里的条目不会丢失，会统一移到“未分类”

## 为什么保存时不用重新输入主密码

成功解锁后，插件会把：

- 解锁后的 vault
- 当前会话里的主密码

暂存在 `chrome.storage.session`。

这意味着：

- 关闭弹窗再打开，当前浏览器会话里通常不用重新输入主密码
- 点击“锁定”后会清掉
- 浏览器重启后也会清掉

它不会写入 WebDAV，也不会长期保存在本地磁盘配置里。

## 登录后提示保存

使用步骤：

1. 先打开插件并解锁
2. 去目标网站登录
3. 插件会识别标准登录表单
4. 登录页跳转后，右下角会提示“保存到 Password WebDAV？”
5. 你确认保存后，插件才会重新加密并上传到 WebDAV

插件不会静默自动保存，必须由你确认。
